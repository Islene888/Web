How to Use Our Catalog

  1. Search: Use the search form above to find specific books by title, author, or keyword.
  2. Browse: View our featured collection in the table above.
  3. Check Availability: The "Available" column shows how many copies are currently available for checkout.
  4. View Details: Click "View Details" to see complete information about any book.
  5. Reserve a Book: If a book is available, you can reserve it from the book's detail page.

Status Legend

  • Available: Multiple copies available for checkout
  • Limited: Only one copy available
  • Unavailable: All copies are currently checked out
