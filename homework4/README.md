# Homework 4: Responsive Vallejo Public Library Website

## 项目概述
这是瓦列霍公共图书馆的响应式网站实现，基于作业2的HTML结构和作业3的设计文档创建。网站完全响应式，支持手机、平板和桌面设备。

## 文件结构
```
homework4/
├── README.md                    # 项目说明文档
└── responsive_website/          # 响应式网站文件
    ├── index.html              # 主页 (必须文件)
    ├── catalog.html            # 图书目录页面
    ├── book_detail.html        # 图书详情页面
    └── styles.css              # 统一的响应式CSS文件
```

## 功能特性

### HTML页面功能
1. **index.html (主页)**
   - 图书馆地址和开放时间
   - 图书证申请表单
   - 联系信息
   - 最新消息部分
   - 图书馆服务列表

2. **catalog.html (图书目录)**
   - 图书搜索功能
   - 按类别和可用性筛选
   - 完整的图书列表
   - 图书可用性状态

3. **book_detail.html (图书详情)**
   - 完整的图书信息
   - 库存数量和可用性
   - 图书预订表单

### 响应式设计特性

#### 移动设备 (< 768px)
- 单列布局
- 垂直导航菜单
- 适配触摸屏的按钮大小
- 16px字体防止iOS缩放
- 优化的表格显示

#### 平板设备 (768px - 1023px)
- 双列网格布局
- 水平导航菜单
- 适中的字体大小
- 平衡的间距

#### 桌面设备 (≥ 1024px)
- 三列网格布局
- 增强的悬停效果
- 大字体和宽松布局
- 专业的设计风格

#### 大屏幕设备 (≥ 1440px)
- 最大容器宽度1400px
- 更大的字体和间距
- 优化的大屏体验

## 设计实现

### 颜色方案 (基于作业3设计文档)
- **主色调蓝色**: #2E5A87 (头部、导航、主要按钮)
- **次要绿色**: #4A7C59 (链接、成功状态、次要元素)
- **强调金色**: #D4A574 (重点按钮、高亮、行动号召)
- **中性灰色**: #F5F5F5 (背景、卡片容器、分隔线)
- **深色文字**: #333333 (所有正文文字)

### 字体设计 (Google Fonts)
- **主字体**: Open Sans (正文、表单、按钮)
- **标题字体**: Merriweather (标题、重点文字)
- **字体层级**:
  - H1: 2.5rem (移动端2rem)
  - H2: 2rem (移动端1.5rem)
  - H3: 1.5rem (移动端1.25rem)
  - 正文: 1rem

### 可访问性特性
- WCAG AA级对比度标准 (≥4.5:1)
- 语义化HTML结构
- 键盘导航支持
- 高对比度模式支持
- 减少动画模式支持
- 适合6-90岁用户的可读性

## 技术实现

### CSS特性
- CSS自定义属性 (CSS Variables)

- 移动优先的响应式设计
